Acceptance cue

Accept the Claude Code and Codex path for forward testing. Treat Gemini CLI and Antigravity as explicit follow-up verification, not as live-proven provider paths.

Opening mental model

The provider choice changes the outer boundary, not the run behavior.

Settings choose a provider and model. Eido keeps one provider-neutral completion boundary, then either calls OpenRouter or crosses the Electron bridge to an authenticated local CLI. Result text returns through the existing run and result-routing path.

Feature parity

The same provider boundary now covers every current run shape.

Ask runs, group compression, conversations, follow-ups, variations, and composed Ask chains keep their existing admission, context, streaming, cancellation, compaction, and result behavior. They differ only at the selected provider boundary.

Settings UX

The AI Models area keeps one provider picker, one optional local command field, one model list, and one active model. Onboarding is the installed command plus existing CLI sign-in.

Persistence

Provider and model are stored with the Idea. Harness commands are device-local settings. Existing Board AI settings remain compatible.

Runtime boundary

The browser development surface does not expose the Electron harness bridge. Local provider proof belongs to the packaged Electron runtime.

Residual gaps

The feature is additive, but local harnesses are not identical APIs.

Claude Code and Codex are the strongest current proof because both ran on this machine. The remaining provider rows are honest boundaries, not hidden failures.

Provider-specific trade-off

Local harnesses normalize text and attachments, but not every remote option maps one-to-one. Eido preserves variation intent in the prompt because these CLIs own sampling; Codex emits completed agent-message events rather than token deltas. Attachments are staged locally and described to the CLI rather than sent as one OpenRouter payload.

Model-list scope

The active Idea owns an editable catalog for every provider. Switching providers restores the selected provider's catalog and active model; device-local command paths remain outside Idea persistence.

Decision boundary

The implementation is ready for forward testing of OpenRouter, Claude Code, and Codex. Gemini CLI and Antigravity require environment-specific proof. Web subscriptions need a different integration boundary and should not be implied by these settings.

## Arbitrations

1. **Curve input jacks**: the controllers report ships a POSITION input
   jack on the curve; the primitives report deferred the GAIN jack for
   opening the same control-input seam. Ruling: the seam opens ONCE, for
   POSITION only (it is the envelope concept's payoff — a STAGE control
   driving where the mod sits in its lifecycle, emission speaking the
   sampled values). GAIN stays deferred. No other control grows input
   jacks this round.
2. **SELECT vs FORK**: both are choice-shaped; they ship as DIFFERENT
   parts. SELECT chooses CONTENT (one-of-N authored options, speaks its
   option's frame, jackless). FORK routes the MODEL's process (decide
   scaffold, paths). The palette keeps them apart (CONTROLS vs PROCESS).
3. **STAGE control**: honest where the playhead was a lie because the
   position EMITS (the user's session genuinely has a phase); scrub
   remains momentary and non-emitting. STAGE is anatomically a slider
   with named stops — ships as a preset configuration of the slider
   kind, not a new kind, once the named-stops rider lands.
4. **BRAINSTORM**: not a pack (100% roster overlap with EXPLORER); ships
   as three preset value chips on EXPLORER (SURVEY / BALANCED / DECIDE).
5. **ANCHOR pack**: flagged weakest by its own designer (constellation
   reads control-agreement, not answer-focus). Ships LAST and only if it
   still earns its slot when seen in hand; otherwise demote to a
   visualizer-less starter.
6. **Artifact cables**: a SECOND cable family (square jacks, wider ink,
   non-mating with signal jacks — refusal by silence, no error states).
   It does NOT join the signal coercion matrix. Prototype renders the
   chain and THE PLAN strip; artifact CONTENTS are engine-surface.
7. **Engine-surface record** (PRD boundary, per the locked UI-skin
   decision): the run plan itself — executing chains, decision points,
   judge loops, artifact contents, provenance, intervention. The
   prototype simulates the PLAN (a pure function of board state), never
   fakes runtime results.

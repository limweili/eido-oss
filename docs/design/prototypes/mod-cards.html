MODS: ONE CLASS

Every mod is a control and its own picture. Touch the value to change it. Nothing wires to anything; each mod stands alone. + grows a mod where growing makes sense, and every option removes from its right edge. Click any name to rename it. The gear holds each mod's few settings and its option prompts; the eye opens the mod context, including the quiet line that tells the AI how to read the values.

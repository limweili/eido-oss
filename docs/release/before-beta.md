# Before a public release

Eido is free and uses user-owned provider access. The former account, purchase,
and control-plane beta checklist is retired by [ADR 0051](../adr/0051-free-open-source-byok-only.md).

Use [Desktop Release Captain](../agents/desktop-release-captain.md) for certified
packages, signing, publication, and update delivery. No account setup, Stripe
catalog, managed-provider credential, PostgreSQL financial canary, or commercial
feature flag is a release prerequisite.

Before publishing the GPLv3 project, review the
[open-source handover](../agents/open-source-handover.md), including remaining
owner costs and external services that repository deletion does not shut down.
Keep real Profiles outside build/test proof and public history.

One Graph, Three Views Map

Use this to decide where a feature belongs before an agent starts coding.

Thin waist: Eido's Board records are the source of truth. Canvas, context, execution, and playback are projections from those records.

Fast Decision Test

If it must be saved

It probably belongs in Board records first, then projected outward.

If it changes pixels

It probably belongs in the canvas view, scene derivation, or renderer adapter.

If it changes AI input

It belongs in the graph/compiler path and needs an inspectable trace.

If it changes AI output

It needs a Run and Output Version provenance story.

If it changes history

Decide whether it is Undo, Playback, both, or neither.

One Useful Phrase

Please implement this as a projection from Board records, not as a second source of truth. Name the owning record, the projection module, and the test that proves they stay in sync.

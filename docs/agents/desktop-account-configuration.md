# Desktop account configuration retired

Eido no longer has accounts, sign-in, sign-up, Clerk, or an AI control plane.
Desktop builds require no account environment variables or account preflight.
Configure a user-owned OpenRouter key in Settings, optionally add a Linkup key,
or select a supported locally installed AI tool.

See [ADR 0051](../adr/0051-free-open-source-byok-only.md) and the
[open-source handover](open-source-handover.md). Former account configuration is
available only in Git history and must not be restored as a release requirement.

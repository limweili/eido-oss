# Rich Intent Capture

## Product Thesis

Eido should help people see the shape of their thinking, not just count their work.

The user is drawn to activity artifacts like GitHub contribution grids and Apple Health rings because they create a visible relationship with effort over time. But Eido's opportunity is different. The subject is not labor, exercise, or habit compliance. The subject is thought: captured, shaped, connected, revisited, and eventually folded into larger structures.

The desired artifact should make a user feel: "I recognize this. I made this. That shape came from my thinking."

## The New Intent

The strongest new input is a tension between generative richness and personal familiarity:

> I am also inspired by progressively generated content from games where there is a certain kind of randomness. But that randomness goes through this rendering engine or simulation engine.

That inspiration matters because Eido's board can become visually alive without every mark being hand-designed. But the randomness cannot be generic decoration. It must be constrained by the fixed input of what the user actually captured.

> The input stays fixed, such as what's been captured, and each of those fixed items contributes to a design element of the board.

The system can use procedural rules, but those rules must act on real board material:

- a thought's position,
- its size and kind,
- its color or region,
- the cluster it belongs to,
- the connections created around it,
- the moments it was revisited,
- the time window being represented.

The important constraint:

> Once a thought is formed then that image needs to remain so the randomness gets locked in.

The generator may create texture, jitter, shape variants, and density. But once the artifact exists, it should behave like ink: stable, replayable, and recognizable.

## Recognizability Is The Product

The user's strongest correction is that the artifact must preserve familiarity with the board itself:

> After a day of work in thinking and shaping the ideas and zooming and navigating across this board where I've really anchored certain areas within the board to different colors ... I start to grow a sense of familiarity with that shape and that color.

The user can point to a board region without reading it. That embodied spatial memory is more important than a clean external metaphor.

Implication: the activity artifact should not start from a calendar grid. It should start from the board as a map.

Calendar, week, month, and periodic views can still exist, but they should be containers for board portraits, not the underlying spatial logic. The core visual unit is not a day square. It is a compressed projection of the board's own low-detail form.

## Emotional Target

The artifact should feel like a journal, a print, or a field study sheet:

- proud, not guilty,
- personal, not comparative,
- alive, not gamified,
- durable, not disposable,
- recognizable, not homogeneous,
- beautiful enough to revisit,
- honest enough to mean something.

The goal is not to close rings every day. The goal is to preserve the visible trace of thinking while it was being shaped.

## Non-Negotiables

1. **Board geography survives compression.** Region, location, size, and color matter because the user created them.
2. **The artifact is derived from real captured activity.** No decorative shapes that pretend to be meaning.
3. **Procedural variation must be deterministic.** Seeded randomness can make marks feel alive, but it cannot drift.
4. **The image locks.** A formed mark should remain stable even if the board later moves on.
5. **The system resists homogeneity.** Standardized primitives are useful, but every board should carry its own color and structure.
6. **The tone is anti-guilt.** No streak pressure, grades, or comparative dashboards.
7. **Zoom disclosure is essential.** A high-level artifact should eventually disclose the board itself.

## Product Tension

The biggest design tension is:

> How much procedural invention can Eido add before it stops feeling like the user's own board?

A working principle:

**Determinism first, variation second.**

The generator should use variation for tactility, density, and legibility. It should not invent the core composition. The core composition comes from the board and its history.

## Research Stance

This track should explore activity language as a projection of Eido's one graph, not as a standalone analytics product. The board is already the user's memory palace. The activity language should reveal that memory at different altitudes.
